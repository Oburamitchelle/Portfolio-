#Personal portfolio website

##Overview

This repository contains the source code for my **personal portfolio website**. The site showcases my skills, projects, and professional background as a software developer, highlighting my work in web development, API design, and database management.
The portfolio is designed with a focus on performance, clean architecture, and modern user interface interactions.

##Features

-Responsive modern **UI design**
-Interactive project showcase
-Smooth scrolling and animated transitions
-Custom navigation with **mobile hamburger menu**
'Contact section with direct communication links
-Optimized layout for multiple screen sizes

##Tech Stack

Frontend: HTML5, CSS3
Interactions: Vanilla JavaScript (ES6+)
